# Python Password Manager

A desktop password manager developed using Python and Tkinter.

## Features

- Generate random passwords
- Save website login information
- Search saved credentials
- Store data using JSON
- Graphical User Interface (GUI)

## Technologies Used

- Python
- Tkinter
- JSON
- Random module

## Skills Demonstrated

- Functions
- Lists and dictionaries
- File handling
- JSON data storage
- GUI development
- Random password generation
- User input and validation

## Project Description

This project is a desktop-based password manager created with Python.
It provides a graphical interface for generating passwords, saving
login information, and searching stored credentials.

## How to Run

Run:  python main.py
